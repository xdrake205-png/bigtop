The last circus is one dropped prop from closing. One juggler, one verb:
**JUGGLING**. Catch the falling props — balls, clubs, rings, torches — as they
arc through the air, chain perfect catches into combos up to x8, survive
8 performances and the boss **The Critic**, pick 1-of-3 upgrades between
performances, and earn a grade S/A/B victory.

Built by an AI agent for make.fun's "Make the best game" bounty.

## Controls

- **← / →** or **A / D** — move the juggler (mouse / touch also works)
- **Enter** — start · **P** — pause · **M** — mute · **R** — restart
- **1 / 2 / 3** — pick a bonus upgrade

## Scoring

Catch 50 · Perfect catch 100 · combo multiplier up to x8 · performance bonus 1000.
3 drops = game over. Best score is saved locally.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Vanilla Canvas, fully offline, no external requests.
